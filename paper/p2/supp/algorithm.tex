\section{The algorithm and its termination}\label{sec:alg}

We fix the encoding for the verifier of Section~\ref{sec:certificate} and prove that the machine, with the dimension and the number of balls as runtime inputs, halts.

\subsection{Input and output}\label{sec:alg-input}

\begin{definition}[Input]\label{def:alg-input}
An input consists of integers $n\ge2$, $k\ge1$ and names (Definition~\ref{def:efd-interface}) of $C,c_1,\ldots,c_k$
and of the $2nk$ coordinates of $s_1,\ldots,s_k$. They are supplied as two oracle streams: the capacity stream,
whose value at $\langle i,p\rangle$ is the precision-$p$ approximation of $c_i$ for $1\le i\le k$ and of $C$ for $i=0$ and for $i>k$;
and the centre stream, whose value at $\langle\langle i,p\rangle,l\rangle$ is the precision-$p$ approximation of the
$l$-th coordinate of the $(i+1)$-st centre. A rational input is given by its constant name. The promises, hypotheses of the termination theorem that are not tested, are that
$(n,k,C,c)$ is admissible and the closed balls $B(s_i,c_i)$ are pairwise disjoint (\Mref{Theorem}{thm:main}).

The output is a natural number $\langle B,\ulcorner e\urcorner\rangle$, where $B\ge1$ and $e$ is a polynomial program
(Definition~\ref{def:certificate-program}). It denotes $\Hfin=\beta_BP_e$; expanding the sums and products of $e$
gives the rational coefficients of $P_e$.

An Epoch input is an integer $k\ge9$ and a name of $\eps\in(0,1)$. It stands for
\begin{equation}\label{eq:alg-epoch-data}
 n=2,\quad R=\left(\frac{k}{1-\eps/2}\right)^{1/4},\quad
 C=\pi R^2,\quad c_i=\pi,\quad s_i=(3i-3,0,0,0).
\end{equation}
\end{definition}

\subsection{Finite encoding}\label{sec:alg-searches}

Tuples and lists of naturals are coded by iterated pairing, and rationals by the triple code of Definition~\ref{def:certificate-program}. The rational operations ($+$, $\times$, negation, $|\cdot|$, $\max$, inverse of a nonzero rational, strict comparison by cross multiplication with positive denominators) are integer operations on codes, without reduction to lowest terms. A polynomial program is a list of instructions $\langle\tau,v\rangle$ read right to left with a stack: tag $0$ pushes the constant with code $v$, tag $1$ pushes $x_v$, tag $2$ replaces the top two entries by their sum, and other tags by their product. A missing entry counts as $0$, and the value is the final top ($0$ if the stack is empty). This reading is total, every expression has a code, and the same recursion computes $h_B(e)$ and $\partial_je$. A vector of dimension $d$ is a list of $d$ rational codes, and any other code reads as $0$. Evaluating $F_e$ at a rational point clips the arguments and interprets $\partial_je$. An Euler step is one evaluation plus $d$ rational operations, and the table is primitive recursive in $N$. The grid node with index $g<(2^m+1)^d$ has coordinates $-Q+2Q\nu_l/2^m$, where the $\nu_l$ are the base-$(2^m+1)$ digits of $g$. Table~\ref{tab:alg-deps} lists the data of the verifier.

The radius names $r_i=\sqrt{c_i/\pi}$ and $R=\sqrt{C/\pi}$ come from the capacity stream by Corollary~\ref{thm:efd-radii}. For an Epoch input, the source radius name is the constant $1$ and the centres are rational constants. The name of $R$ is obtained from that of $\eps$ by forming $1-\eps/2$ (Proposition~\ref{prop:efd-closure}), inverting it using $1-\eps/2>2^{-1}$, multiplying by $k$, and applying Lemma~\ref{lem:efd-roots-direct} twice. No names of $C$ or $c_i$ are formed.

\subsection{The machine}

\begin{construction}[Algorithm]\label{cons:alg-main}
On input $(n,k)$ and the oracle streams, put $d=2n$. For $\mathrm{st}=0,1,2,\dots$ decode $\mathrm{st}$ as a candidate
$(p,B,Q,m,N,e)$ and compute its failure count $\Phi(n,k,\mathrm{st})\in\N$, a sum of failure indicators: one for the condition
$B,Q,N\ge1$, one for each source-box test, and one for each node-source pair that passes neither the discard test nor
both trajectory tests of Definition~\ref{def:certificate-checks}, all evaluated with the names at precision $p$. So
$\Phi=0$ exactly when the candidate passes. Stop at the first $\mathrm{st}$ with $\Phi(n,k,\mathrm{st})=0$ and output $\langle B,\ulcorner e\urcorner\rangle$.
The Epoch machine is the same search with $n=2$ and the names described above; its runtime input is $k$ and its only
oracle is the name of $\eps$.
\end{construction}

\begin{lemma}[Totality of the checker]\label{lem:alg-searches}
For fixed oracle streams, $(n,k,\mathrm{st})\mapsto\Phi(n,k,\mathrm{st})$ is a total function, recursive in the
oracles. Each value uses finitely many oracle queries.
\end{lemma}

\begin{proof}
Decoding is primitive recursive. Radius names are total with finitely many queries per value (Corollary~\ref{thm:efd-radii}), and centre approximations are single queries. The checker performs $kd$ source-box tests and, for each of the $k(2^m+1)^d$ node-source pairs, a discard test. If the discard test fails, it also runs an $N$-step Euler table with $N+1$ plateau rows and one terminal test. The quantities $\Theta,\rho,E$ are rational in the candidate, all loop bounds are computed from $(n,k,\mathrm{st})$, and interpretation is total. Hence $\Phi$ arises from the oracles by composition and bounded recursion.
\end{proof}

\begin{theorem}[Termination and correctness]\label{thm:alg-main}
For every input satisfying the promises of Definition~\ref{def:alg-input}, Construction~\ref{cons:alg-main} halts,
and its output $\langle B,\ulcorner e\urcorner\rangle$ satisfies: $\beta_BP_e$ is $C^\infty$, vanishes for
$z\notin(-3B/4,3B/4)^{2n}$, and satisfies $\Pack(n,k,C,c,s)$. The machine is partial recursive relative to the oracle
streams, uniformly in $(n,k)$. For an Epoch input it halts with $\beta_BP_e$ satisfying $\Pack(2,k,\pi R^2,\pi,s)$ for
the data \eqref{eq:alg-epoch-data}, and $k/R^4=1-\eps/2>1-\eps$.
\end{theorem}

\begin{proof}
The machine is an unbounded minimisation of the total oracle-recursive $\Phi$ (Lemma~\ref{lem:alg-searches}) followed by a primitive recursive output map, hence partial recursive in the oracles, uniformly in $(n,k)$. By Theorem~\ref{thm:certificate-exists} a passing candidate exists, and since decoding inverts encoding its code $\mathrm{st}_0$ satisfies $\Phi(n,k,\mathrm{st}_0)=0$. So the search halts at some $\mathrm{st}\le\mathrm{st}_0$, and the output is correct by Theorem~\ref{thm:certificate-sound}.

For an Epoch input, the data \eqref{eq:alg-epoch-data} are admissible with disjoint closed source balls by the proof of \Mref{Corollary}{thm:main-epoch}. The machine's names give the centres, the source radius $\sqrt{\pi/\pi}=1$ and the target radius $R$, so the argument applies with $n=2$; finally $R^4=k/(1-\eps/2)$ and $\eps>0$.
\end{proof}

\begin{remark}[Epoch form]\label{rem:alg-epoch}
The same verifier serves the Epoch input and all four cases of the construction (\Mref{Table}{p2:tab-ver}):
the cases enter only the proof that a passing certificate exists.
\end{remark}
